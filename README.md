## ⚠️ Mengapa Muncul Halaman "Autarkeia.com - Ready for Development"?

Domain `autarkeia.com` adalah domain komersial yang dimiliki broker domain dan sedang dijual seharga $29/bulan. Domain tersebut **bukan milik kita dan belum dibeli**.

Jika diisi pada kolom **Custom Domain** di GitHub Pages, GitHub akan mengira domain tersebut milik Anda, sehingga ketika dibuka browser akan mengarah ke website broker tersebut.

### Solusi:
- Cukup gunakan URL gratis dari GitHub Pages:
  👉 **https://dukewilz.github.io/web/**
- Jika ingin nama kustom gratis (misal: `autarkeia.vercel.app`), Anda bisa mendeploy ke **Vercel** dengan 1-klik menghubungkan repo ini.
